# 键盘输入桥 macOS v0.2.10

## 授权状态修复

- 已定位“系统设置开关已开、工具仍显示未授权”的主要原因：测试版使用 ad-hoc 临时签名，不同构建的代码身份不同，旧授权记录无法匹配新版本。
- 临时签名安装包升级时自动重置本应用旧的辅助功能与输入监控记录，再启动新版进行干净授权。
- 正式 Developer ID 签名具有稳定 TeamIdentifier，安装器会保留其已有授权。

## 更及时的状态反馈

- 后台权限检测由每秒一次提高到每 0.5 秒一次。
- 授权按钮点击后在 0.2、0.5、1、2、5、10 秒复查。
- 权限状态旁新增紧凑的“刷新状态”按钮，立即显示 macOS 官方 API 返回结果。
- 输入监控刚获批时自动重建全局监听器，不再要求手动关闭再开启复制监听。

## 用户自助修复

- “清理旧授权记录并重新授权”默认隐藏，仅在用户主动刷新后仍未授权时展开，授权成功后自动收起。
- 操作前显示说明和二次确认。
- 只重置 `local.keyboardbridge.app` 的 Accessibility 与 ListenEvent 记录，不影响其他应用。
- 清理后自动打开辅助功能设置，并明确提示依次完成两项授权。
