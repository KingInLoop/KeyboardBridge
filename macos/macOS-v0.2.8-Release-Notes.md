# 键盘输入桥 macOS v0.2.8

## 手动粘贴

- 开启或关闭“监听 ⌘C”时，都可以点击待输入区并直接按 `Command+V`。
- 待输入区标题栏新增“粘贴”按钮，可将剪贴板文本插入当前光标或替换选中内容。
- 新增标准“编辑”菜单，补齐撤销、重做、剪切、复制、粘贴和全选。
- 监听开关仅控制 `Command+C` 后的自动载入与自动唤起，不影响手动编辑流程。

## 本版改进

- 菜单栏状态项使用专用单色键盘与输入箭头图标，可随系统深浅色自动切换。
- 默认使用靠屏幕右侧的 380×600 紧凑面板，最小可缩至 300×360。
- 窄窗口下设置项和权限按钮自动纵向排列；发送、停止和状态始终固定在底部。
- 标准红黄绿窗口按钮恢复正常尺寸，安全提示关闭按钮也扩大了点击区域。
- 可一键安装到 `~/Applications/KeyboardBridge.app` 并从固定路径重启。
- 可一次申请辅助功能和输入监控并自动复查；详细设置入口会打开当前缺失项。
- 构建脚本自动寻找 Developer ID，支持可选自动公证；没有证书时继续生成本机测试包。

## 与 Windows v0.2.5 对齐

- Dock、访达和应用切换器现使用与 Windows v0.2.5 一致的 KeyboardBridge 品牌图标。
- 加入 1–30 秒输入倒计时，输入按钮和状态栏同步显示剩余秒数。
- 加入小 80%、中 100%、大 125% 三档界面大小，选择会在重启后保留。
- 使用可滚动卡片式布局；窗口空间不足时纵向滚动，操作按钮保持可用尺寸。
- 待输入内容区域独立显示字符数和行数。
- 安全提示每次启动显示，5 秒后出现关闭入口。
- 倒计时提示统一为“请点击要输入的位置”，覆盖远程桌面、浏览器、终端和普通桌面应用。
- 输入过程中锁定预览及设置，避免倒计时期间输入计划发生变化。
- 多行模式下，Enter 后至少保留 150 ms 缓冲。

## macOS 平台特性

- 保留辅助功能与输入监控权限的分项状态和直达设置按钮。
- 保留当前运行副本路径，便于确认授权对象。
- 保留 Dock、菜单栏、最小化和关闭后恢复入口。
- `Option+Esc` 可以在倒计时或输入过程中停止。
- Apple Silicon 与 Intel 使用同一个 universal 应用包。

## 安全默认值

- 默认把换行替换为空格；只有主动勾选后才发送 Enter。
- 演练模式不发送键盘事件。
- 日志不保存输入正文，只记录事件、数量、耗时和短哈希。
- 复制监听可以关闭；关闭后不读取剪贴板，也不会因普通复制自动唤起。
