# KeyboardBridge Windows 设计文档

版本：v0.2.5

## 设计目标

KeyboardBridge 将一段经过用户确认的文本转换为可见、可停止的键盘输入。设计重点是明确控制权、跨场景适用、默认安全和两个 Windows 实现的一致体验。

适用位置包括普通桌面输入框、浏览器、远程桌面、Web/本地终端、虚拟机控制台，以及限制普通粘贴但允许键盘输入的区域。产品文案不把能力描述为仅服务于云桌面。

## 交互模型

### 输入前

- 文本始终在编辑区可见，用户可检查和修改。
- 安全提示提醒用户不要输入密码、令牌或私钥。
- 回车默认转换为空格；只有用户主动勾选后才发送回车。
- 演练模式计算输入计划但不发送按键。

### 点击输入按钮后

- 编辑和设置控件暂时禁用，避免输入计划在倒计时中变化。
- 状态栏显示 `请点击要输入的位置（N 秒后输入）`。
- 按钮本身继续显示剩余秒数。
- 文案使用“位置”而不是“云桌面”或“窗口”，因为目标可能是同一应用中的控件、浏览器页面或任意桌面程序。

### 输入期间

- 状态栏明确显示正在输入。
- `Ctrl+Alt+Esc` 作为全局停止操作。
- 完成、取消和失败都有可见状态反馈。

## 信息架构

界面从上到下包括：

1. 可关闭的安全提示。
2. 待输入内容及字符/行数统计。
3. 字符间隔、倒计时和界面大小。
4. 回车、演练和 Ctrl+C 监听开关。
5. 输入与停止按钮。
6. 状态栏。

小、中、大分别对应 80%、100%、125%。中档是设计基准。窗口高度不足时由根容器滚动，底部按钮具有独立最小高度，不参与剩余空间压缩。

## 技术架构

### WinForms

- C#/.NET 8，自包含单文件。
- `TableLayoutPanel` 与 `FlowLayoutPanel` 负责响应式布局。
- 字体、控件和窗口按用户档位同比例缩放。
- P/Invoke 负责全局热键、低级键盘钩子、窗口置顶和 `SendInput`。

### Tauri

- HTML/CSS/JavaScript 负责交互和响应式布局。
- Rust 负责系统托盘、注册表设置、剪贴板读取、全局热键和键盘发送。
- 前后端通过 Tauri command 与 event 通信。
- 操作按钮使用显式高度与最小高度；窄窗口通过页面滚动而不是压缩按钮。

## 输入策略

- 常见 ASCII 字符优先映射为物理虚拟键和扫描码，以兼容远程环境。
- 无物理映射的字符使用 Unicode 输入路径。
- 默认将换行替换为空格；允许回车时发送回车键。
- 字符间隔限制在安全范围内，回车使用更长的最小间隔。

## 安全与隐私

- 不保存待输入正文。
- 不上传文本，不依赖网络服务。
- 不尝试提权、注入或规避目标程序安全机制。
- 复制监听可以关闭，关闭后卸载相应键盘钩子。
- 安全提示每次启动显示，5 秒后允许关闭。

## 一致性要求

以下内容必须在 WinForms 与 Tauri 中保持一致：

- 设置名称、默认值和持久化语义。
- 倒计时提示、状态反馈和错误含义。
- 输入规则、停止热键和安全默认值。
- 缩放档位、最小尺寸与窄窗口滚动体验。

任何面向用户的文案修改都应同时搜索两个实现和交付文档，避免再次出现平台或场景限定不一致。
